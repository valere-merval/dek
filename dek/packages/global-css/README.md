# @fair/global-css

Dieses Package beinhaltet:

- CSS Reset
- congstar Font-Families (werden von dem [fair-fonts Repo](https://git.congstar.net/congo-web/design-system/fair-fonts) bereitgestellt)
- congstar Basis Styles

## Installation

> **Achtung**  
> Dieses package muss _nicht_ installiert werden, wenn @fair/react benutzt wird!

```shell
npm install @fair/global-css
```
