# Tools für Gitlab CI 

Um in der Pipeline einen Merge Request zu öffnen, falls in einem Branch etwas neues pushed wurde gibt es hier das passende Tooling.

Es wird [gitbeaker](https://github.com/jdalrymple/gitbeaker) für die Aufrufe gegen Gitlab genutzt.

[commander](https://github.com/tj/commander.js) wird verwendet um auf der cli die Kommandos zu Verfügung zu stellen.
